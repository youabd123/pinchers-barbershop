# ✂️ Pincher's Barbershop

A modern website for **Pincher's Barbershop in Gothenburg**, inspired by the barbershop's Jamaican roots and identity. 🇯🇲

The website is currently under development.

## 🌐 About the project

The goal is to create a clean, modern and responsive website where customers can:

- Learn more about Pincher's Barbershop
- Explore services
- Meet the team
- View previous haircuts and styles
- Easily continue to Bokadirekt to book an appointment

## 🎨 Design

The visual identity is inspired by the colors of the Jamaican flag:

- 🖤 Black
- 💚 Green
- 💛 Gold / Yellow

The design combines a modern barbershop style with Pincher's Jamaican roots and Gothenburg identity.

## 🛠️ Built with
